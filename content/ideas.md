Formato: video corto (Reel/TikTok). Categorías sugeridas para no depender de un solo nicho:

- **Demos rápidas**: "Automaticé X en Y minutos" (mostrar un workflow n8n o script Python en acción)

- **Tips**: trucos de n8n, Python, SQL para automatizar tareas comunes
- **Detrás de cámaras**: construyendo una automatización para un cliente (con permiso/anonimizado)
- **Educativo**: "3 procesos de tu negocio que puedes automatizar hoy"
- **Casos de uso por industria**: rotar entre e-commerce, agencias, servicios, etc. (mantiene el nicho amplio pero da variedad)
