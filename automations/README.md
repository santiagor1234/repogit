# Automations

Cada automatización va en su propia subcarpeta, por ejemplo:

```
automations/
  lead-sync-crm/
    README.md      # qué hace, para quién, stack usado
    main.py
  reporte-semanal/
    README.md
    main.py
```

El `README.md` de cada subcarpeta debe explicar: el problema que resuelve, el stack (Python/n8n/SQL), y si es una demo propia o un proyecto de cliente (anonimizado si aplica).
